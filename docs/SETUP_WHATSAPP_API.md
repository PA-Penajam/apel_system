# Setup Fonnte untuk APEL System

Dokumentasi lengkap cara setting Fonnte WhatsApp API untuk notifikasi jadwal apel.

---

## Apa itu Fonnte?

Fonnte adalah provider WhatsApp API berbasis di Indonesia dengan harga terjangkau dan kemudahan setup.

| Paket | Harga | Kuota | Durasi |
|-------|-------|-------|--------|
| Free Trial | Rp 0 | 50 pesan | Selamanya |
| Bronze | Rp 150.000 | 1.000 pesan | 6 bulan |
| Silver | Rp 500.000 | 5.000 pesan | 6 bulan |
| Gold | Rp 1.000.000 | 12.000 pesan | 6 bulan |

**Untuk PA Penajam:** Dengan 2 broadcast per minggu, paket Bronze (1.000 pesan) cukup untuk **~6 bulan**.

---

## Langkah 1: Pendaftaran Fonnte

1. Buka website: https://fonnte.com/
2. Klik **"Daftar"** atau **"Register"**
3. Isi data registrasi:
   - Nama lengkap
   - Email aktif
   - Nomor WhatsApp
   - Password
4. Verifikasi email
5. Login ke dashboard

---

## Langkah 2: Hubungkan WhatsApp

1. Di dashboard Fonnte, cari menu **"Device"**
2. Klik **"Tambah Device"**
3. Buka WhatsApp di HP Anda:
   - WhatsApp Settings → Linked Devices → Link a Device
4. Scan QR Code yang ditampilkan di dashboard Fonnte
5. Status akan berubah menjadi **"Online"**

**Penting:** HP harus selalu terhubung internet agar WhatsApp tetap aktif di Fonnte.

---

## Langkah 3: Dapatkan Token API

1. Di dashboard, cari menu **"Settings"** → **"API"**
2. Anda akan melihat:
   - **API Token** (contoh: `eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...`)
   - **Device Token** (contoh: `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`)
3. **Copy kedua token** dan simpan di tempat aman

---

## Langkah 4: Konfigurasi di Aplikasi APEL

### Edit file .env

Buka file `.env` di project APEL dan tambahkan:

```env
# ===========================================
# FONNTE WHATSAPP CONFIGURATION
# ===========================================

# Token dari dashboard Fonnte (wajib)
FONNTE_TOKEN=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9xxxxxxxxxxxxx

# Target Group ID (opsional - jika kosong akan kirim ke semua grup)
# FONNTE_TARGET_GROUP=
```

### Cara Menemukan Token

```
Dashboard Fonnte
│
├── Settings → API
│   ├── API Token: eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
│   └── Device Token: xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
│
└── Device
    ├── Status: ✅ Online
    └── Nomor: 628xxxxxx
```

## Langkah 6: Test Koneksi

1. Buka browser
2. Akses: `https://apel-pa-penajam.test/fonnte/test`
3. Jika muncul **"✅ Koneksi Fonnte berhasil!"** → Berhasil
4. Jika muncul **"❌ Koneksi Fonnte gagal"** → Cek konfigurasi .env

## Cara Penggunaan

### 1. Generate Jadwal

1. Login ke aplikasi APEL
2. Buka menu **"Jadwal Apel"**
3. Isi **Tanggal Mulai** dan **Tanggal Selesai**
4. Klik **"Generate Jadwal"**

### 2. Broadcast ke Grup WhatsApp

1. Di kartu jadwal, klik tombol **WhatsApp** (icon share)
2. Konfirmasi dengan klik **"OK"**
3. Pesan terkirim ke grup WhatsApp

### 3. Cek Sisa Kuota

1. Buka: `https://apel-pa-penajam.test/fonnte/quota`
2. Akan menampilkan: `📊 Info Fonnte - Sisa Kuota: XX/XX pesan`

## Troubleshooting

### Error: "Token tidak valid"

| Penyebab | Solusi |
|----------|--------|
| Token salah | Copy ulang dari dashboard Fonnte |
| Token expired | Generate token baru di Fonnte |
| Spasi di token | Pastikan tidak ada spasi |

### Error: "Device offline"

| Penyebab | Solusi |
|----------|--------|
| HP mati | Nyalakan HP dan internet |
| WhatsApp keluar | Scan QR Code ulang |
| Session expired | Login ulang di Fonnte |

### Error: "Gagal terkirim"

| Penyebab | Solusi |
|----------|--------|
| Rate limit | Tunggu 1-2 menit |
| Kuota habis | Beli paket tambahan |
| Grup penuh | Kurangi anggota grup |

## Cara Test dengan cURL

```bash

curl -X GET "https://api.fonnte.com/api/device" \
  -H "Authorization: {TOKEN_ANDA}"

# Kirim pesan test
curl -X POST "https://api.fonnte.com/api/send" \
  -H "Authorization: {TOKEN_ANDA}" \
  -F "target=6281234567890" \
  -F "message=Halo ini test dari APEL"
```

## Backup Device

**Penting:** Jika HP mati atau WhatsApp di-install ulang, device akan offline.

**Solusi:**
1. Catat nomor HP yang digunakan
2. Jika offline, scan QR Code ulang di dashboard
3. Device akan aktif kembali
